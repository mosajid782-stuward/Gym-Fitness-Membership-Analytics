Gym & Fitness Center Membership Analytics

Project Overview

This project analyzes gym membership data using Python, Pandas, NumPy and Matplotlib.

Dataset

12_gym_membership.csv

Project Structure

- SRS: Project documentation
- src: Jupyter Notebook and Python source code
- data: Dataset
- README.md: Project information

How to Run

1. Install required libraries:
   "pip install pandas numpy matplotlib jupyter"
2. Open "src/gym_membership_analysis.ipynb" in VS Code.
3. Select Python Kernel.
4. Click Run All.

Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
